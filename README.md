# ⚡ Rushikesh Jagtap — Developer Portfolio

> An interactive, cyberpunk/dark-themed developer portfolio featuring dynamic Three.js 3D canvas visuals, custom mouse physics, interactive certification showcases, and responsive telemetry design.

---

## 🛠️ Tech Stack & Highlights

- **Frontend Core:** Semantic HTML5, CSS3 Custom Properties, Modern Vanilla JavaScript (ES6+)
- **Design System:** Tailwind CSS (CDN), Custom Glassmorphic Cards, Lucide Icons
- **Interactive Visuals:** 
  - Dynamic 3D particle constellation canvas with cursor-reactive gravity
  - Section-reactive custom cursor halo & telemetry badge
  - Interactive Project Case Studies with live GitHub modals & architectural stats
  - Direct Certificate verification links with preview badges
- **Deployment:** Vercel / Netlify / GitHub Pages ready (Zero-build static site)

---

## 📂 Project Structure

```
├── index.html       # Single-page portfolio structure & SEO metadata
├── style.css        # Custom animations, glassmorphism, glowing badges, scrollbars
├── script.js        # Three.js canvas, sound FX synthesis, filter engine & cursor physics
├── MyImage.jpeg     # Hero profile portrait
├── README.md        # Documentation
└── .gitignore       # System ignores
```

---

## 🚀 Local Development

Simply open `index.html` in any modern web browser or serve it with VS Code's **Live Server** extension:

```bash
# If using Python simple HTTP server:
python -m http.server 8000
```
Then visit `http://localhost:8000` in your browser.
